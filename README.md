## Why I Quit

One day I had a calendar booked from **8am to 8pm**.  
One hour lunch break. Back-to-back meetings.

I took a screenshot of that day.

I remember thinking:

> “I never want to live like this again.”

I had too many ideas.  
Too much curiosity.  
Too much execution speed.

But in large teams:
- Consensus slows things down  
- Ideas need buy-in  
- Execution waits  
- Meetings multiply  

I realized something important:

The way I think and execute does not work in high-consensus environments.

So I left.

Not because I hated building.  
But because I love building too much.
